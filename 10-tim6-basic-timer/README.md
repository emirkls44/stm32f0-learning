# 10 – TIM6 basic timer interrupt

TIM6 generates an update interrupt every second; `HAL_TIM_PeriodElapsedCallback()` toggles the
blue LED (LD4, PC8).

| Item | Value |
|---|---|
| Timer clock | 8 MHz (HSI, no PLL) |
| Prescaler | 8000 − 1 → 1 kHz counter |
| Period (ARR) | 999 → 1000 counts = 1 s |

For a 100 ms period set `Period` to 99. Clock, GPIO and NVIC are configured by hand (`msp.c`,
`it.c`) rather than generated by CubeMX.
